# Slim, RUNTIME-ONLY dependency set for the Vercel serverless deployment.
# Vercel's Python builder prefers a requirements.txt next to the function
# entrypoint over the project-root one, so this intentionally overrides
# ../requirements.txt for the deployed function -- local dev/Docker/tests
# keep using the full ../requirements.txt (training, tests, uvicorn).
#
# pandas / scikit-learn / scipy / numpy / xgboost / joblib are ALL
# deliberately excluded. Scoring uses app/ml/lite.py, a pure-Python
# reimplementation of the trained (Logistic Regression) pipelines'
# predict_proba -- validated to match the real scikit-learn pipeline to
# floating-point-epsilon precision across every application in the
# database (scripts/export_lite_models.py). None of those heavy libraries
# are imported by the request-serving code path at all anymore.
#
# If a future retrain picks a non-Logistic-Regression winner for either
# model, export_lite_models.py will refuse to export a (necessarily
# wrong) lite spec for it, and app/ml/scoring.py falls back to the full
# joblib+scikit-learn path for that model -- which this slim requirements
# file does NOT provide. In that case, add scikit-learn/joblib/pandas
# (and xgboost, if that's the winner) back here before deploying.
